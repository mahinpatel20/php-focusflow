# FocusFlow - PHP Mini Project

A simple and unique PHP mini project: a **Study Focus Session Tracker**.

## Features
- Add a study subject
- Select session duration
- Track completed sessions
- View total study minutes
- Delete sessions
- Data is stored in a simple JSON file (no MySQL required)

## Requirements
- XAMPP/WAMP or PHP 8+
- Web browser

## Run
1. Copy the `php_focusflow` folder into `htdocs`.
2. Start Apache in XAMPP.
3. Open: `http://localhost/php_focusflow/`

## Files
- `index.php` - main application
- `style.css` - UI styling
- `data/sessions.json` - stored session data
- `output.png` - sample output screenshot
